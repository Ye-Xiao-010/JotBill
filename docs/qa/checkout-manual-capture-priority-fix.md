### 7.2 对"三次消失"叙述的裁定

实施者叙述 checkout -b / update-ref / commit 三次"成功但消失"。reflog 只支持**一次确证丢失 + 一次成功恢复**：全 reflog 仅一条 0000→x 恢复行（若 update-ref 修复也曾丢失需二次修复，应出现多条）。"再次消失"已被实施者自认是**错误目录下执行的误报**；"commit 对象创建但 ref 更新消失"同样无 reflog 痕迹（f8365e8 前无第二条无标签行），大概率属同类误诊。**结论：一次真实异常（19:25~19:40 窗口），非持续性故障。**

### 7.6 恢复程序（提交对象不会丢，reflog 可靠）

```powershell
# 1. 从 reflog 尾部取最新提交 SHA（首列旧值、第二列新值，取新值）

# 2. shell 直写回分支引用（替换 <sha> 与分支路径）
New-Item -ItemType Directory -Force .git\refs\heads\fix | Out-Null

git status; git log --oneline -3
```
