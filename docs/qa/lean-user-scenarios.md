# 精简版用户场景对照表（2026-10-24）

> **用途**：产品视角的场景承诺 ↔ 代码现实的一一对照，作为 L1 真机验收的场景清单。
> **来源**：基于 HEAD（`aac4f0c` + 场景审查修复批）逐条代码核实（三个审查代理 + 主审），
> 每条标注核实状态：✅ 成立 / ⚠️ 部分成立 / ❌ 不成立。行号会漂，复现用符号名。
> **口径基准**：弹窗延迟与命中率以 `lean-version-acceptance.md` L1 的 A/B 档为准
> （A 档=支付成功页即时弹出；B 档=延迟数秒或离开支付应用后弹出；转待确认+通知兜底不算丢账）。
