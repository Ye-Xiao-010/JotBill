# 银行图标

用于账户的储蓄卡 / 信用卡银行识别。每个图标提供：

- `<code>.svg`：源文件（1024 viewBox，方形徽标，白底圆角方块）
- `<code>.png`：512×512 透明底导出（圆角外透明）
- `banks.json`：`code / 名称 / 简称 / 别名` 映射，供后续账户匹配使用
- `overview.png`：23 家银行总览图

## 扩展

新增银行时：从同一来源下载 `<code>-rect.svg`，导出 512×512 PNG，并在
`banks.json` 补充 code / 中文名 / 简称 / 别名。需要覆盖更多城商行、农商行时，
可以从来源仓库继续补充；本次先收录六大行、全国性股份制银行与头部城商行。
